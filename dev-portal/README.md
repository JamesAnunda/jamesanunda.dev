# Development Projects Homepage

Upload the contents of this folder to the document root for `dev.jamesanunda.dev`.

The project cards link to these directories under the same document root:

- `test/` — staging copy of the main website
- `arcola-tractor-pull-dashboard/` — Arcola Tractor Pull Dashboard

Create those directories in cPanel and upload each project's production build into its corresponding directory. The existing cPanel directory password should remain applied to the development subdomain root.
